# Baby Alpaca

- **Platform**: AlpacaHack (Daily)
- **Category**: Misc / Trivia (Welcome 🌱)
- **Released**: 2026-10-01
- **Flag**: `Alpaca{cria}`

## Challenge

> What is a baby alpaca called? Give the term that comes from Spanish and is
> also used in English. Submit its English spelling as four lowercase letters
> in the format `Alpaca{...}`.

## Solution

アルパカ（やラマなどラクダ科）の赤ちゃんはスペイン語由来の **"cria"** と呼ばれ、
英語でもそのまま使われる。4文字。

## Flag

```
Alpaca{cria}
```
